# Git Journey Portfolio

A small portfolio website built while learning Git and GitHub step by step.

## Features
- Navbar, Skills, Projects and Contact sections
- Built with HTML, CSS and JavaScript

## Tech stack
- HTML5
- CSS3
- JavaScript

## Run locally
```bash
git clone https://github.com/shreyansh-987/git-portfolio.git
cd git-portfolio
```
Then open `index.html` in your browser.

## What I practised
Commits, branching, merging, conflict resolution, stash, rebase and pull requests.
